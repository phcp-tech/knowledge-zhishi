## 什么是知识

[知识](https://zhishi.io) 是一个编写和分享领域知识的平台。作者用 Markdown 写文章。每篇文章用一个 HKC 编码分类，读者可以按主题查找知识。作者还可以把文章永久备份到 [Arweave](https://www.arweave.org/)。

## 核心概念

### 1. HKC

HKC 是一种以人为中心的知识分类方法。它从四种关系出发：人与自我、人与神、人与人、人与自然。

- 详细介绍：https://zhishi.io/articles/HKCiFa2evWBvH1wu

- 网站：https://hkc.wiki

### 2. 领域知识

领域知识是一个领域内全部知识的总和。学习和掌握领域知识，可以获得相应的技能和工具，完成一项完整的工作。

详细介绍：https://zhishi.io/articles/Uysieha2evWhR5xZ

### 3. 永久存储

文章每次发布的版本都会保留，并且不会被修改。作者还可以用自己的钱包把某个版本上传到 Arweave。Arweave 是一个永久的去中心化网络。只有上传的内容与已发布的版本一致时，知识才记录这笔 Arweave 交易。

## 功能

### 读者

- 不需要账号即可阅读已发布的文章。
- 按 HKC 编码、主题、标签、标题、作者、语言和难度查找文章。
- 置顶文章排在前面。每篇文章显示浏览数。

### 作者

- 用 Markdown 写文章，保存草稿。读者看不到草稿。
- 为每篇文章选择一个 HKC 编码。知识自动补充 HKC 路径和名称。
- 发布文章。每次发布生成一个新版本，旧版本仍然保留。
- 撤回已发布的文章，以后可以重新发布。
- 为文章上传图片，为个人资料上传头像。
- 用 ArConnect 或 Arweave.app 钱包把某个版本备份到 Arweave。
- 关注文章。
